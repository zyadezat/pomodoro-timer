# ⏳ Pomodoro Focus Timer CLI

A lightweight command-line Pomodoro productivity timer featuring real-time dynamic terminal display.

## ✨ Features
- **Dynamic Countdown**: Displays live `MM:SS` timer updates directly in the terminal using `\r` carriage return.
- **Validation**: Accepts positive integer inputs for focus minutes.
- **Completion Alerts**: Notifies the user clearly when the focus session finishes.
- **Zero Dependencies**: Relies solely on Python standard libraries.

## 🛠️ Concepts & Technologies
- Python 3.x
- Built-in `time` module
- String Formatting & Dynamic Terminal Output
- Exception Handling (`ValueError`)
